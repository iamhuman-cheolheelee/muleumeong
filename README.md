# 물으멍: 제주 공공데이터에 말로 물으면, 원본을 계산해 숫자로 답하는 AI 에이전트

제주데이터허브(jejudatahub.net) 공개 목록 1,259종에서 도민 질문에 맞는 데이터를 찾고, 원본 파일을 내려받아 **코드로 계산**한 뒤, 숫자마다 계산에 쓴 원본 행 번호를 붙여 답합니다. 작은 로컬 모델은 문장만 다듬고, 모델 문장의 숫자·단위가 계산 결과와 하나라도 다르면 버리고 규칙 문장을 씁니다.

## 구조

```mermaid
flowchart LR
  Q[도민 질문] --> U[1 질문 이해<br/>조사 제거·도민 말 사전·모델 키워드 확장]
  U --> S[2 데이터 찾기<br/>글자 2-gram BM25 + 낱말 포함률 → RRF k=60]
  S --> F[3 원본 불러오기<br/>내장 사본 → 허브 실시간 → 미리보기<br/>UTF-8·CP949·xlsx 판별]
  F --> C[4 코드로 계산<br/>흐름·순위·비교 · 합계 행 제거 · 누적값은 마지막 달]
  C --> W[5 답 쓰기·숫자 검산<br/>캐시 → 로컬 Qwen2.5-3B → 규칙 문장]
  W --> A[답 + 그래프 + 원본 행 + pandas 재현 코드]
```

| 층 | 기술 |
|---|---|
| 서버 | Go 1.27.3 · chi · huma(OpenAPI): 단일 바이너리가 API와 화면을 함께 서빙 |
| 화면 | Vite · React · TanStack Router/Query · Tailwind v4 (`web/`, 빌드 결과 `web/dist` 내장) |
| 모델 | llama.cpp `llama-server` + Qwen2.5-3B-Instruct Q4_K_M(약 2GB, 저장소에 없음): GPU 6GB(GTX 1060급)에 모델 전체를 올려 동작(`-ngl 99`), GPU가 없으면 CPU로도 돌지만 느림 |
| 데이터 | `internal/agent/data/`: 카탈로그 1,259종 메타, 열 이름 사전, 허브 원본 사본 8종(예시 7종 + 1352), 공공데이터포털 공개 원본 36종, 미리보기 1,062종(각 40KB 이하). 원본 전체로 계산하는 데이터 46종(열 사전 `data/schema.json`) |

## 실행

```bash
# 1) 화면 빌드(이미 web/dist 가 있으면 생략)
cd web && pnpm install && pnpm build && cd ..
# 2) 서버
go build -o muleumeong . && ./muleumeong          # http://127.0.0.1:18164
# 3) (선택) 로컬 모델: 없으면 규칙 문장으로 답한다
llama-server -m qwen2.5-3b-instruct-q4_k_m.gguf --port 18165 -c 4096 -ngl 99
```

설정은 `.env.example` 참고(환경변수). 외부 API 키가 필요 없습니다.

## 사용 설명서

1. **질문하기**: 입력창에 평소 말투로 묻거나 예시 질문을 누릅니다. 답 문장, 그래프, 계산에 쓴 원본 행, pandas 재현 코드, 일한 순서 5단계가 나옵니다. 「찾은 데이터」를 펼쳐 다른 후보로 다시 계산할 수 있습니다.
2. **데이터 찾기**: 질문에 대한 후보 순위와, 도민 말투 시험 질문 20개의 검색 결과(5위 안 19/20, 1위 17/20)를 봅니다.
3. **품질 점검**: 허브 전체의 파일 형식, 로그인 필요 여부, 인코딩, 합계 행이 섞인 표를 셉니다.
4. **확인하는 법**: 5단계 설명과 같은 숫자를 직접 다시 내는 방법.

## API

| 경로 | 설명 |
|---|---|
| `GET /api/ask?q=&pin=` | 질문 → 답(단계·사실·근거 행·재현 코드). `pin`=데이터 id 고정 |
| `GET /api/search?q=` | 후보 데이터 순위 |
| `GET /api/seeds` | 미리 계산한 예시 질문 7개 |
| `GET /api/golden` | 시험 질문 20개 검색 결과 |
| `GET /api/quality` | 허브 품질 점검 수치 |
| `GET /api/dataset/{id}` | 데이터 메타 |
| `GET /api/health` | 상태 |

## 데이터 명세

| 파일 | 내용 | 출처 |
|---|---|---|
| `data/catalog.json` | id·제목·분류·설명·태그·기관·로그인 여부·원본/미리보기 파일 정보·API 여부·갱신일 | 제주데이터허브 공개 목록(2026-10-26 수집) |
| `data/colnames.json` | 영문 열 이름 → 한글 뜻 | 허브 미리보기 열 이름에서 정리 |
| `data/csv/{id}.csv` | 허브 원본 사본 8종(예시 7종 + 1352, 원 형식 유지: CSV·xlsx) | 허브 원본 내려받기 |
| `data/pub/{id}.csv`, `data/pub.json` | 같은 기관들이 공공데이터포털에 로그인 없이 공개한 제주 원본 36종(인구·노인·외국인·출산·관광객·우도·공항·터미널·교통사고·주요 관광지·렌터카·물가·귀농·다문화·건강·인구이동·차량·크루즈 등)과 출처 URL | data.go.kr 공개 파일(2026-10-26 수집) |
| `data/schema.json` | 열 사전 71종: 열마다 역할·단위·합계 행·기본값 (생성: `python3 tools/schema_src.py`) | 직접 작성 |
| `data/prev/{id}.csv` | 미리보기 파일(40KB로 자름): 로그인이 필요한 데이터의 열 확인·시범 계산용 | 허브 미리보기 |
| `cache/*.json` | 모델 응답 캐시(같은 입력이면 같은 문장) | 로컬 모델 출력 |

모든 데이터는 제주데이터허브·공공데이터포털 공개 데이터이며 개인정보를 담지 않습니다. 이용 조건은 각 데이터 페이지를 따릅니다.

## 시험

```bash
go test ./...   # 시험 질문 20개 검색 재현율(5위 안 70% 이상) 등
# 예시 밖 질문 평가(서버를 띄운 뒤)
python3 tools/evalrun.py http://127.0.0.1:18164 evalset-e/evalset.json out.json
```

| 평가셋 | 질문 수 | 처음 측정(답 있음 정답) | 지금 | 틀린 답(처음 → 지금) | 답 없는 질문 거절 |
|---|---|---|---|---|---|
| A `evalset` (개발용) | 48 | - | 33/33 | 0 | 100% |
| 보류셋 `evalset-holdout` (개발용) | 40 | - | 27/27 | 0 | 100% |
| C `evalset-c` (개발용) | 42 | - | 29/30 | 0 | 100% |
| D `evalset-d` (개발용) | 45 | - | 30/30 | 0 | 100% |
| E `evalset-e` (개발용) | 45 | - | 30/30 | 0 | 100% |
| **F `evalset-f` (블라인드)** | 45 | 13/30 (43.3%) | 19/30 (63.3%) | 1 → 0 | 15/15 |
| **G `evalset-g` (블라인드)** | 50 | 9/34 (26.5%) | 12/34 (35.3%) | 2 → 0 | 16/16 |
| **H `evalset-h` (블라인드)** | 50 | 18/34 (52.9%) | 21/34 (61.8%) | 2 → 1* | 16/16 |

A~E는 오류를 보며 규칙을 고친 개발용 세트입니다. F·G·H는 코드를 보지 않은 별도 에이전트가 원본을 직접 계산해 만든 블라인드 세트이고(`compute.py` 동봉), 실력에 가장 가까운 값은 각 세트의 처음 측정입니다. 블라인드 첫 측정에서 틀린 답은 답할 수 있는 질문 98개 중 5건(약 5%)이었고, 답 없는 질문 47개는 모두 거절했습니다. 확신이 없으면 추측하지 않고 이유를 밝혀 거절하도록 설계했기 때문에, 정답률보다 틀린 답이 적은 쪽을 택했습니다.

\* H27은 판정이 갈립니다. 질문의 「예약」을 에이전트는 예약 분석 데이터(913, 호텔 2,590건)로 답했고, 정답표는 구매 기록(910, 호텔 798건)을 썼습니다. 표에는 틀린 답으로 셉니다.

## 오류·제약사항

| 상황 | 동작 |
|---|---|
| 로컬 모델(:18165)이 꺼짐·6초 초과(답 전체는 10초 안) | 캐시 → 정해진 문장으로 답함(숫자는 같음) |
