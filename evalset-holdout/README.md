# evalset-holdout

독립 작성한 hold-out 평가셋(40문항: answerable 26, unanswerable 14). Go 코드·tools/·evalset/ 은 보지 않았다.

## 방법
- 입력: `muleumeong/internal/agent/data/catalog.json`(제목 확인용), `muleumeong/full/{id}.bin` 원본(CSV utf-8/cp949, XLSX).
- 데이터셋 15종: 1294 1358 1363 1364 1357 1356 1352 1219 1287 875 914 912 910 878 1349(불가 문항만). 이전 사용 id(1351 915 900 877 872 1295)는 제외.
- 정답은 pandas(`python3 -I`, 격리 venv)로 원본에서 직접 계산, `why` 에 계산식 기재. 값은 소수 2자리 반올림.
- 기준일 2026-10-26, "작년"=2025.
- 함정: 지수 평균(합산 금지, H07), 누계 vs 당월(H14·H15·H17), 소계 행(1363 '약용작물', H10), 반복 측정 행의 고유 개수(H18·H22), 단위 의도(몇 집/몇 곳/몇 톤), 특정 월, 최대·최소, 범위 밖 연도, 지역 불일치(제주시·하와이·제주 분리 불가), 원인·예측, 존재하지 않는 항목.
- 방향 문항(H03·H13)의 value 는 변화량(끝-시작).

## 재생성
스크립트는 저장소 밖 `/tmp/hs/build.py` 에서 실행했다(휘발성).
